
## Gotchas

- **Design tokens now match Figma exactly** (`app/globals.css`, updated 2026-08-06): `--brand: #621eeb`, `--brand-dark: #4d17c0`, `--brand-tint: #efe9fd`, `--accent: #2cbdb8`, `--accent-text: #1a7f7a`, `--accent-tint: #dff7f5`, `--ink: #241a35`, `--muted: #675f78`, `--line: #e7dfef`. This is a real site-wide token update (nav, footer, buttons, cards all repaint), not scoped to Main Header — sanity-checked against `layout.tsx`/`page.tsx` for contrast issues, none found.
- **`components/search-bar.tsx` gained a `variant?: "default" | "hero"` prop.** `"default"` (unchanged) is used by `components/buscar-content.tsx`'s filter toolbar; `"hero"` is the Figma pill styling used by `main-header.tsx`. Logic (`NavDropdown`, `CityAutocomplete`, `router.push`) is identical between variants — only the container/button classNames branch.
- Figma specifies **Fraunces** (display/headings) and **Quicksand** (body/UI) fonts; the project still loads **Poppins** (`--font-display`) and **Inter** (`--font-body`) via `next/font/google` in `app/[locale]/layout.tsx`. Not swapped yet — this is why the Main Header heading wraps to 3 lines instead of Figma's 2 (Poppins is wider per character than Fraunces at the same pixel size). Swapping the global font loader affects every page, so it's left as an explicit follow-up rather than done silently mid-component-build.
- The photo/blob/mask composition in `main-header.tsx` uses percentage-based absolute positioning + CSS `mask-image` (with `-webkit-` fallback) rather than reproducing Figma's exact `container-type`/`hypot()`/pixel mask-position math — visually close (verified against `.caché/main-header/assets/export-full.png` and a live Playwright screenshot) but not pixel-identical, and will drift slightly at very narrow/very wide viewports since it's an approximation, not a literal port.
